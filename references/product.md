# OneCall 的能力与交付边界

OneCall 提供语音 Agent 市场、团队员工管理和通话记录。按用户行业、目标与工作边界选择员工，不承诺一个员工适用于所有业务。

本 Skill 0.1.0 的实际能力：

| 操作 | 完成方式 |
| --- | --- |
| 搜索员工、查看行业与场景、简介、可用试听音频 | CLI 直接读取公开市场 |
| 创建、选择音色、提交改进反馈、加入团队、网页语音和电话体验 | CLI 返回对应网页；用户在网页登录并完成操作 |
| 查已发布团队员工、外呼营销员、通话、任务及进度 | CLI 调用团队开放 API |
| 建外呼任务、上传 JSON 名单、开始/恢复/暂停 | CLI 生成预览，获得授权后提交；沿用服务端权限及启动前检查 |
| 登录、余额、充值、API Key 配置 | 网页完成；Skill 不获取浏览器会话或短信验证码 |

没有开放的员工写 API 就不伪造命令成功，也不把本地编辑文件说成云端员工已经改变。已创建员工的开场白与摘要在详情中为只读快照；改进反馈不等于已经修改话术。不要宣称已支持原生 WorkBuddy 卡片、MCP 服务、自动短信登录、音色克隆或资料录音训练。

费用以当前团队在 OneCall 网页显示的费率和确认信息为准，团队通话费率包含线路与算力，不采用其他供应商的价目表。未完成真实通话不能写成测试成功；有试听示例也不等于该员工当前可以试打。
