# OneCall 电话数字员工 Skill

在支持 Agent Skills 和本地命令执行的 AI 助手中查找电话员工、查询团队通话和任务，并在确认后管理外呼任务。

当前版本 **0.1.0**，协议 **1**。运行环境为 **Node.js 20+**；无第三方运行依赖，无需安装全局 CLI。

## 能做什么

| 功能 | 方式 |
| --- | --- |
| 搜索公开数字员工、查看详情与试听入口 | 直接查询，无需 API Key |
| 创建员工、调整配置、体验语音或电话 | 返回 OneCall 网页入口，在网页完成 |
| 查询团队员工、通话记录、任务与进度 | 使用团队 API Key |
| 创建任务、导入 JSON 名单、启动/恢复/暂停外呼 | 先预览，授权后确认提交 |

## 安装

把这句话发送给支持本地工具执行的 AI 助手：

```text
请帮我安装 OneCall 电话技能：https://github.com/onecallx/onecall-skill
先读取 SKILL.md，保留完整目录，安装后告诉我如何配置 OneCall 站点。
```

也可以手动克隆到宿主支持的 Skills 目录。下面以 Codex 为例（已有同名目录时先核对本地修改）：

```sh
git clone https://github.com/onecallx/onecall-skill.git ~/.codex/skills/onecall-phonecall
```

Claude Code、WorkBuddy、OpenClaw 的常见目录见[安装与配置](references/setup.md)。Cursor 使用其实际配置的 Skills 目录。安装后重新加载技能或新开对话。仅支持网页聊天、不支持本地命令的工具无法直接运行本 Skill。

## 连接 OneCall

默认连接官方服务 `https://api.16x.tech`（网页 `https://app.16x.tech`），无需配置即可使用：

```sh
node ~/.codex/skills/onecall-phonecall/scripts/onecall.mjs status
node ~/.codex/skills/onecall-phonecall/scripts/onecall.mjs market list --q 回访
```

自建部署时，通过 `ONECALL_BASE_URL` 与 `ONECALL_WEB_URL` 指定自己的源地址；线上必须使用 HTTPS，不要附加 `/api` 或 `/v1`。

公开查询无需密钥。团队操作需要在 OneCall 开发者页面创建 API Key，并在本机配置 `ONECALL_API_KEY`，或通过 `ONECALL_CREDENTIALS_FILE` 指向私密 JSON 文件。不要把密钥粘贴进对话或提交到仓库。`status` 只检查本地配置，不代表服务器授权成功。

本 Skill 依赖服务端的营销员外呼 OpenAPI（`/v1/agents`、`/v1/calls`、`/v1/outbound/*`）。若这些命令返回 `HTTP_410`（`OPENAPI_ENDPOINT_RETIRED`），说明该 OneCall 站点已升级为任务模板版接口，本版本暂不兼容；请核对站点版本，详见[安装与配置](references/setup.md)。

最小权限：员工查询 `assistant:read`；通话查询 `calls:read`；任务查询 `outbound:read`；任务写入还需 `outbound:write`。

## 开始使用

直接用自然语言描述电话业务需求即可触发本技能，无需先提到 OneCall：

```text
帮我找一位客户回访员工，先展示岗位与体验入口，不要发起通话。
帮我打一批客户回访电话，名单我来提供。
查看当前团队的员工和最近通话。
为客户回访准备一个外呼任务，先让我确认任务参数。
```

创建、上传名单与启停任务会先返回预览。确认编号绑定目标和内容，15 分钟内有效。执行确认后，同一编号不会重复发送请求。遇到 `unknown` 状态时先核对操作记录和服务端业务状态，不重传、不重拨；本地防重不等于跨机器服务端幂等。实际拨打条件与费用以 OneCall 当前团队配置为准。

## 真实用户完整流程（照着走一遍）

下面每条 **你说** 都可以直接复制发给装了本技能的 AI 助手。整个流程分两个阶段：**先体验**（零配置、零通话、零费用），**再实战**（首次配一次密钥，之后每步都是"预览 → 你确认 → 执行"）。

### 阶段一：找员工、试听（不需要任何配置）

**第 1 步 · 挑岗位**

你说：`帮我找一位客户回访员工，先展示岗位与体验入口，不要发起通话`

你会看到：市场在招的电话员工列表（岗位名、行业、一句话职责），每人一个体验入口链接。
要点：这一步不会拨打任何电话。

**第 2 步 · 看详情、试听**

你说：`第 1 个不错，给我它的详情和试听入口`

你会看到：该岗位的完整介绍 + 体验页链接（形如 `https://app.16x.tech/market/<岗位名>`）。
你要做：浏览器打开链接，按网页要求**登录、验证、确认费用**后试听，或用"拨打给我"体验真实效果。
要点：体验都在网页完成，助手不会代拨、不会替你确认收费。

**第 3 步 · 不满意就换（可选）**

你说：`有没有医疗行业的？`　或　`再看看教育行业的回访员工`

你会看到：按行业重新筛选的结果，继续第 2 步即可。

### 阶段二：给自己的客户打回访（首次配一次密钥）

**第 4 步 · 首次配置密钥（只做一次）**

你说：`我要用团队功能，API Key 怎么配？`

你会看到：OneCall 开发者页链接（https://app.16x.tech/developer）。
你要做：

1. **网页创建 Key**：登录后在开发者页创建 API Key（`sk_live_` 开头），按用途勾最小权限——员工 `assistant:read`、通话 `calls:read`、任务 `outbound:read`，要做外呼再加 `outbound:write`。

2. **本机配置**（二选一，密钥只存本机）：

   方式 A · 环境变量（当前终端有效）：

   ```sh
   export ONECALL_API_KEY="sk_live_你的密钥"
   ```

   方式 B · 私密文件（推荐，持久；技能会校验权限必须 0600）：

   ```sh
   mkdir -p ~/.onecall
   printf '{"apiKey": "sk_live_你的密钥"}' > ~/.onecall/creds.json
   chmod 600 ~/.onecall/creds.json
   export ONECALL_CREDENTIALS_FILE="$HOME/.onecall/creds.json"
   ```

   要每次自动生效，把 `export` 那行加进 `~/.zshrc` / `~/.bashrc`；Windows 用 `setx ONECALL_API_KEY "sk_live_…"`。

3. **验证**：对助手说 `看下配置状态`，显示密钥已配置即可（真正的权限校验由服务端在首次团队查询时完成）。

安全三原则：密钥**不贴进对话**、**不提交进仓库**；疑似泄露到开发者页**直接吊销重建**，换新后只更新本机那一个文件。

**第 5 步 · 看家底**

你说：`查看当前团队的员工和最近通话`

你会看到：团队员工列表和最近的通话记录。

**第 6 步 · 创建外呼任务（先出预览，你确认才建）**

你说：`为客户回访准备一个外呼任务，先让我确认任务参数。营销员用小诗，每天 9 点到 18 点呼，并发 1`

你会看到：任务预览——用哪个员工、时间窗、并发数、费用提示，并等你确认（15 分钟内有效）。
你要做：核对无误后回复 `确认`。
你会看到：任务创建成功，状态**已暂停**——不会自动开工，此时也还没有任何号码。

**第 7 步 · 导入名单（先出预览，你确认才传）**

你说：`导入名单，文件在 ~/leads.json，先别开打`

你会看到：预览显示将导入几个号码、目标任务当前状态、计费提醒（**上传到运行中的任务可能立即拨号**）。
你要做：确认。
你会看到：导入成功。可再说 `看下任务里的号码` 核对（`+86` 前缀会自动清成 `138…`）。

**第 8 步 · 启动 / 暂停 / 看进度（每步先出预览）**

你说：`开始外呼` ——确认后启动；服务端会先做启动前检查，条件不满足会直接告诉你原因，不会盲目重试。
你说：`先暂停` ——确认后停止后续拨打。
你说：`现在进度怎么样？` ——已拨 / 等待数量。
你说：`查一下今天的通话记录` ——通话列表。

### 出问题怎么办

| 你遇到 | 该怎么做 |
| --- | --- |
| 提示需要 API Key | 回到第 4 步配置；密钥永远别贴进对话 |
| 401 / 403 | 核对密钥有效期与权限（员工 `assistant:read`、通话 `calls:read`、任务 `outbound:read`+`outbound:write`） |
| 结果"未确定"（unknown） | **不要**让助手重传名单、重建任务或重拨试探，先查任务进度和通话记录核对实际状态 |
| 启动被拒（启动前检查未通过） | 按返回的原因补齐员工线路/配置；不要改参数硬试 |

### 预期节奏（自查对照）

1. 找员工、试听全程**零通话、零费用**；真正拨号只发生在你确认"开始外呼"之后。
2. 创建任务、导入名单、启停任务**一定先出预览**，你确认才执行；同一确认重复提交不会重复发送请求。
3. 助手不会替你在网页完成登录、验证或付费；给链接只代表"这一步去网页做"。

> 本流程全部环节已于 2026-11-20 实测：阶段一对官方线上服务逐项走通，阶段二在本地真实 OneCall 服务完整走通（含真实创建任务、导入名单、启动前检查拦截与防重提交）。
