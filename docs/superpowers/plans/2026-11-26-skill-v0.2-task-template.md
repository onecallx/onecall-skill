# 技能 v0.2 任务模板适配 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 onecall-skill 从旧营销员外呼 API 完整迁移到服务端 develop 分支的任务模板 OpenAPI，端到端可用（含真实拨打回归）。

**Architecture:** 保持单文件零依赖 CLI（`scripts/onecall.mjs`）与协议 1 JSON 信封不变；改写命令分发、payload 校验、操作端点构造与确认提交路径；文档四件套与测试同步重写。服务端语义见 spec 约束表。

**Tech Stack:** Node.js ≥20 原生（fetch/crypto/fs），node:test，无第三方依赖。

**Spec:** `docs/superpowers/specs/2026-11-26-skill-v0.2-task-template-design.md`

## Global Constraints

- 零 npm 运行依赖；Node ≥20；单文件 `scripts/onecall.mjs`。
- 输出信封不变：`{protocol:1, version:'0.2.0', state, data, next}` + 可选 `error`；五状态机 done/handoff/confirm/unknown/error。
- `VERSION` 常量改为 `'0.2.0'`（package.json、release.json 同步，协议号保持 1）。
- 请求超时 `AbortSignal.timeout(30000)`；凭据/权限校验（0600 文件、0700 目录、属主）与 API key 脱敏逻辑不变。
- 写操作必须先落 operation 记录再经 `operation confirm` 提交；claim 独占、unknown 不重发不变。
- 所有写请求携带 `Idempotency-Key: <operationId>` 头。
- 端点全部使用 develop 面查询参数式（见 spec 约束表）；不得出现 `/v1/agents`、`/v1/calls`、`/v1/outbound/marketers`、路径式 `/v1/outbound/tasks/:id/*`。

## Review Focus

1. **contacts 中 phone 格式非法**（如 `"abc"`、3 位数字）→ create/import 预检即拒绝（INVALID_INPUT），不发出请求。
2. **auto_start=true 且 contacts 为空** → 本地预检拒绝（服务端规则前置）。
3. **legacy 任务执行 control/import** → 单查返回 410，CLI 如实透出 error 且不落 claim（预检失败在 claim 之前）。
4. **重放已确认 operation** → 命中本地 outcome 缓存直接返回，不发请求；本地记录丢失时服务端 Idempotency-Key 兜底（测试断言头存在）。
5. **任务单查与列表参数混用** → `tasks show` 独立路径只带 `task_id`，列表命令永不带 `task_id`（服务端 400 不可触达）。

对应测试已分别落入 Task 3（1、2）、Task 4（3、4）、Task 2（5）。

### Task 3: create/import payload 重定义 + Idempotency-Key 传输支持

**Files:**
- Modify: `scripts/onecall.mjs`（`validatePayload`、`request`）
- Test: `tests/onecall-skill-cli.test.mjs`

**Interfaces:**
- `validatePayload('create', value)` 返回 `{ name, template_id, template_revision, contacts[], auto_start?, client_task_id? }`，其中 contacts 元素 `{phone, name?, variables?, client_contact_id?}`；本地预检：**name 必填非空白 ≤200 字**、template_id 非空字符串、**template_revision 必填正整数**、auto_start 布尔、contacts ≤1000、phone `/^\+?\d{5,20}$/`、name（联系人）≤120、variables 键值均为字符串（键 ≤64、值 ≤500）、`auto_start && !contacts.length` 拒绝。
- `validatePayload('import', value)` 接受 `{contacts:[…]}` 或兼容旧 `{phones|data}`（内部归一为 contacts），其余规则同上（≥1 条）。
- `request(path, { method, body, query, publicAccess, idempotencyKey })`：`idempotencyKey` 存在时设 `Idempotency-Key` 头。
- create/import 预览阶段保持零 HTTP 请求（沿用 v0.1 契约）。

### Task 4: operation 端点迁移与 confirm 提交路径

**Files:**
- Modify: `scripts/onecall.mjs`（`operationPath`、`taskIdentity`、tasks 写命令块、`operation confirm` 块）
- Test: `tests/onecall-skill-cli.test.mjs`

**Interfaces:**
- `operationPath(action, target)` 返回：
  - create → `{ path: '/v1/outbound/tasks', method: 'POST' }`
  - import → `{ path: '/v1/outbound/tasks/numbers', method: 'POST', query: { task_id } }`
  - start/pause → `{ path: '/v1/outbound/tasks/control', method: 'POST', query: { task_id } }`
- control 提交 body：`{ action: 'start' | 'pause' }`（import/create body 由 validatePayload 产出）。
- `taskIdentity(task)` 摘要字段改为 `['id','name','status','state_version','error_code']`。
- 写命令面收窄为 `['create','import','start','pause']`（resume 删除）。
- 预览（confirm）结构：create 展示 `{ name, templateId, templateRevision, contactsCount, autoStart }`（零请求，仅文件内信息；模板详情核对是 Agent 职责，SKILL.md 规则）；import 展示 `{ id, name, status, count }`；start/pause 展示 `{ id, name, status }`；consequence 文案按 spec 第 4 节。
- confirm 提交统一走 `request(spec.path, { method:'POST', body, query: spec.query, idempotencyKey: operationId })`。
- target 预检：`GET /v1/outbound/tasks?task_id=`；410/404 → 如实 error，不落 claim。
